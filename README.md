# Creative Studio OS V4

**AI video, Blender 3D, procedural visuals, motion design, and web asset workflows — an experimental creative production starter.**

> Status: prototype. This public repository is being populated from the Creative Studio OS V4 starter kit. The complete offline package is also available in the original ChatGPT conversation as `Creative_Studio_OS_V4_Public_Repo_Ready.zip`.

## Modules

- **Art Direction:** Dark Luxury, Modern Minimal, Futuristic Digital, Editorial Cinematic.
- **Blender Studio:** reusable shaders, Geometry Nodes concepts, scene automation.
- **Asset Intelligence:** CSV/JSON catalog, file checks, provenance and license tracking.
- **Motion + Web:** SVG, GLB, MP4, WAV, and responsive HTML gallery in the full package.
- **Quality Gates:** creative brief, technical checks, commercial-use and attribution review.

## Release scope

The complete starter kit contains 12 vector originals, 4 procedural GLB models, 4 motion previews and 4 short audio previews, plus PNG thumbnails, catalog, HTML preview and pipeline scripts. These are **prototypes, not client-ready final assets**. Blender execution, 4K renders, usage rights and accessibility still need independent verification.

## Publication

This repository is **public**, but a public repository is not automatically open-source licensed. A source-code license and an asset license must be chosen separately before allowing reuse. Do not add stock assets unless you have redistribution rights.

See [public release checklist](PUBLIC_RELEASE.md), [quality policy](docs/QUALITY_GATES.md), and [source policy](docs/LICENSE_POLICY.md).
