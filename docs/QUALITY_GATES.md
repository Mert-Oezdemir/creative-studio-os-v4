# Creative asset quality gates

1. **Art direction** — clear subject, palette, negative space, composition, visual hierarchy.
2. **Technical** — valid file, consistent dimensions, expected alpha/transparency, no missing media.
3. **Motion** — smooth loops, readable animation, no disruptive flicker; reduce-motion support for web.
4. **3D** — inspect normals, material roughness, topology and model scale; validate GLB imports.
5. **Audio** — check clipping, loudness, mono compatibility and fade/click artifacts.
6. **Provenance** — record source, creator, date, license, derivation, relevant model or prompt.
7. **Commercial approval** — third-party rights, brand concerns and customer approval.
8. **Accessibility** — image alt text, contrast, keyboard navigation, motion preferences.

A prototype can be shared as a demonstration but must not be advertised as production-validated.
