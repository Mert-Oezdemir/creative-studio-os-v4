# Licensing and provenance

A public GitHub repository does not grant a license automatically.

Maintain distinct terms for:
- Source code and scripts.
- SVGs, 3D scenes, audio, images and video.
- External stock assets and fonts.
- Brand/customer-specific deliverables.

Record each external item's canonical source URL, author, applicable license, date retrieved and usage restrictions. **Do not redistribute paid stock assets** through this repository without an explicit redistribution license.

No third-party assets are authorized for upload merely because they are free to download. Before public contributions, check consent and trademarks, and remove embedded metadata or credentials.
